# Repository structure

## Top level

| Path | Kind | Purpose |
|------|------|---------|
| `StreamToM3U.slnx` | Solution (XML) | Lists the application and unit-test projects |
| `StreamToM3U/` | Console application | The tool itself |
| `StreamToM3U.UnitTests/` | Test project | NUnit fixtures and `LoopbackHttpServer` |
| `ARCHITECTURE.md` | Document | Root architecture record |
| `README.md` | Document | Primary user documentation |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `PRIVACY.md`, `LICENSE` | Documents | Policy and process |
| `.github/` | Configuration | Workflows and funding configuration |
| `docs/` | Documentation | This knowledge base |

## Application project layout

| Path | Purpose |
|------|---------|
| `StreamToM3U/Program.cs` | Composition root and run-mode dispatch |
| `StreamToM3U/appsettings.json` | HTTP and logging configuration, copied to output |
| `StreamToM3U/Configuration/Options.cs` | Command-line alias parsing and provider selection |
| `StreamToM3U/Configuration/ApplicationSettings.cs` | HTTP timeout and user agent binding |
| `StreamToM3U/Configuration/StreamProvider.cs` | Provider enumeration (`Website`, `TvSportHd`, `AntenaPlay`, `Streamlink`) |
| `StreamToM3U/DataAccess/DataObjects/ChannelStreamEntity.cs` | XML-serialisable channel entity |
| `StreamToM3U/Logging/MyOperation.cs` | Application operations (`FileDownload`, `ChannelStreamFetching`) |
| `StreamToM3U/Logging/MyLogInfoKey.cs` | Log keys (`ChannelStreamId`, `Url`) |
| `StreamToM3U/Service/IFileDownloader.cs`, `FileDownloader.cs` | HTTP text retrieval |
| `StreamToM3U/Service/IPlaylistUrlRetriever.cs`, `PlaylistUrlRetriever.cs` | Provider dispatch and validation |
| `StreamToM3U/Service/IPlaylistFileGenerator.cs`, `PlaylistFileGenerator.cs` | Batch resolution and output writing |
| `StreamToM3U/Service/Mapping/ChannelStreamMapping.cs` | Entity → service-model mapping |
| `StreamToM3U/Service/Models/ChannelStream.cs` | Batch-mode service model |
| `StreamToM3U/Service/Models/StreamInfo.cs` | Single-resolution request model |
| `StreamToM3U/Service/Processors/IProcessor.cs` | Provider contract |
| `StreamToM3U/Service/Processors/WebsiteProcessor.cs` | HTML playlist-link extraction |
| `StreamToM3U/Service/Processors/StreamlinkProcessor.cs` | Streamlink CLI invocation |
| `StreamToM3U/Service/Processors/TvSportHdProcessor.cs` | TVSportHD browser automation |
| `StreamToM3U/Service/Processors/AntenaPlayProcessor.cs` | AntenaPlay browser automation with disposable registration |
| `StreamToM3U/Utils/WebDriverHandler.cs` | One shared headless `ChromeDriver` and its lock |
| `StreamToM3U/Data/input-ro.xml`, `input-md.xml`, `input-int.xml` | Sample channel lists |

Note: the website provider class is named `WebsiteProcessr` in source (missing final `o`). This
name is used consistently in this documentation and in tests.

## Build outputs

`bin/` and `obj/` are generated by the .NET SDK and are not part of the source contract. Release
archives contain the executable (`StreamToM3U`), `appsettings.json`, and the `Data/` XML files.
